# cuOpt Workshop - Student

This is the student-facing cuOpt workshop package. Open the notebooks in numbered order and replace each `<<<TO DO>>>` marker with working Python code.

## Notebooks

1. `00-Setup-Smoke-Test.ipynb`
2. `01-01-VRP-Solver.ipynb`
3. `01-02-MIP-Solver.ipynb`
4. `01-03-LP-Solver.ipynb`
5. `01-04-QP-Solver.ipynb`

## Support Folders

- `data/`: model and data files used by the notebooks
- `launchable/`: optional backup install script and requirements
- `scripts/`: optional smoke-test helper

Use the `Python (cuOpt Workshop)` kernel.

Note: `00-Setup-Smoke-Test.ipynb` has no TODOs. It is a runnable environment check.
